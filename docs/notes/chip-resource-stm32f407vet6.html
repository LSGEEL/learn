型号解析：STM32F407 产品线 + V（100 引脚）+ E（512 KB Flash）+ T（LQFP）+ 6（-40~85 °C）。 带 TR 后缀（STM32F407VET6TR）为卷带包装，芯片本身相同。 下列参考手册、勘误表、SDK 都是系列级资料，覆盖 F405/407/415/417 等多个型号，使用时请按 F407、512 KB、LQFP100 筛选对应内容。

推荐阅读顺序

  1. 数据手册：先看框图、引脚表、复用功能表、电气参数，确认 512 KB / LQFP100 版本的资源。
  2. AN4488 + AN2867：设计电源、复位、晶振、BOOT 和 SWD 等最小系统。
  3. ES0182：在原理图定稿前，排查会影响硬件设计的勘误。
  4. STM32CubeMX：规划引脚和时钟树，生成初始工程。
  5. RM0090：按需阅读要用到的外设章节（RCC、GPIO、DMA、定时器、通信接口）。
  6. UM1725 + CubeF4 例程：参考 HAL/LL 用法，例程以 STM32F4DISCOVERY 为准。
  7. PM0214：涉及中断优先级、FPU、MPU 或底层优化时再查。
  8. AN2606 / STM32CubeProgrammer：规划量产烧录方式和读保护策略。

缺失或风险项

  • 官方评估板不是 VET6：STM32F4DISCOVERY 使用 STM32F407VG（1 MB Flash）。照搬其例程时，需要修改链接脚本中的 Flash 大小（512 KB）和 Flash 扇区使用（VE 只有扇区 0~7）。
  • 系列级资料：RM0090 同时覆盖 F42x/F43x，其中的 LTDC、DMA2D、SAI、FMC/SDRAM 等外设 F407 并不具备，阅读时要以数据手册为准。
  • 勘误与芯片版本相关：ES0182 中的问题与芯片 revision 有关，需对照实物丝印判断。
  • 部分下载需要登录：STM32CubeIDE、STM32CubeMX、STM32CubeProgrammer 安装包需要 ST 账号登录后下载。
  • 未核实的内容：本报告没有核实 CubeF4 和各工具的当前版本号，也没有找到 ST 官方给出的 VET6 专属参考设计；ECAD 封装和 3D 模型请到产品页的 CAD Resources 获取。
  • 仿冒片风险：F407 市场上存在仿冒或翻新货，量产采购应走 ST 授权分销渠道。
